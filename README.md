# Household Energy Analysis

Анализ суточного энергопотребления дома по датасету UCI
*Individual household electric power consumption* (2006–2007).

## Что делает проект

Скрипт `analize.py`:

1. Читает минутные замеры (`;`-разделитель, `?` → NaN).
2. Склеивает `Date` + `Time` в единый `datetime`.
3. Считает энергию за каждую минуту: `Global_active_power [кВт] × 1/60 [ч] = кВт·ч`.
4. Суммирует энергию по дням.
5. Строит 4 графика.
6. Сохраняет суточные суммы в Excel.

| `daily_energy.xlsx` | суточные суммы энергии, кВт·ч |

## Как читать результаты

**Единицы:**

- `Global_active_power` — **кВт** (мощность в моменте);
- `energy_kwh` — **кВт·ч за минуту** (`мощность × 1/60`);
- `daily` — **кВт·ч/сутки** (сумма по дню).

**Что видно на сэмпле (профиль мощности):**

- ночью ~2,4 кВт с регулярными провалами до 0,2–0,4 кВт → цикл термостата бойлера/обогревателя;
- вечером пики до 6–7,7 кВт (17:44–17:46) → чайник/плита;
- `Sub_metering_2` = 36–37 Вт·ч в 18:03–18:12 и 01:04–01:52 → стирка/сушка;
- `Sub_metering_3` ≈ 17 Вт·ч постоянно → бойлер в дежурном режиме.

**Ошибки интерпретации, которых стоит избегать:**

- не путать мощность (кВт) с энергией (кВт·ч);
- не забывать, что это **один конкретный дом**, а не «люди вообще».
